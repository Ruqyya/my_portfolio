## Wording rules used
- "What the final design delivers" lists qualities of the design. It never states a measured result.
- The `measured` field exists but is empty for every project. Fill it only with sourced numbers.
- "What this shows about my work" is interpretation by the site author (me) of the decisions above it, written in plain language. Edit it freely if it does not sound like you.
